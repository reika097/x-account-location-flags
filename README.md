# Account Location Flags for X（アカウント所在国フラッグ for X）

X（Twitter）の **プロフィール画面** と **ホバーカード**（名前にマウスを乗せると出るプロフィール）で、@ID の右側にそのアカウントの所在国の国旗を表示する Chrome 拡張機能です。
X が VPN やプロキシ経由の可能性ありと判定したアカウントには、国旗の横に赤い **VPN** マークも表示します。

- 所在国のデータは、X の「このアカウントについて」と同じもの（`AboutAccountQuery` の `account_based_in`）を使います。
- VPN の判定には、同じレスポンスの `location_accurate === false` を使います。
- 国旗にマウスを乗せると、国名・接続元（例: `Japan App Store`）・VPN の注意書きが表示されます。
- 国ではなく地域（例: `South Asia`）が返ってきたアカウントには 🌐 を表示します。
- タイムラインやスレッドでは表示しません（一度に大量の問い合わせが必要になり、表示が遅くなるため）。

## 対応言語

ブラウザの言語設定に合わせて、ツールチップ・ポップアップ・ストアの説明文が切り替わります（`_locales/`）。

English（デフォルト）/ 日本語 / 한국어 / 简体中文 / 繁體中文 / Español / Português (Brasil) / Français / Deutsch

国名から国旗への変換は `Intl.DisplayNames` を使っており、X の表示言語が何語でも変換できます。

## インストール

1. このリポジトリを clone するか、「Code」→「Download ZIP」でダウンロードして展開する
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダ（`manifest.json` があるフォルダ）を選ぶ
5. x.com を開く（開いていた場合は再読み込みする）

更新するときは、新しいファイルに置き換えてから `chrome://extensions` で拡張機能の再読み込みボタンを押してください。

## プライバシー

- データのやり取りは X（x.com）とのみ行い、ログイン中の X のセッションを使います。開発者や第三者のサーバーには何も送信しません。
- 取得した所在国情報と設定は、ブラウザ内（`chrome.storage.local`）にだけ保存します。

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/page.js` | ページ側（MAIN world）で動くスクリプト。X 自身の API 通信から認証ヘッダーを取得し、`AboutAccountQuery` を呼び出す。queryId が変わっていた場合は、読み込み済みの JS から自動で探し直す |
| `src/content.js` | プロフィール画面とホバーカードの @ID 要素を見つけ、その右側に国旗を挿入する。X の新旧どちらの DOM でも動くよう、`data-testid` に頼らず「@ID」というテキストで要素を探す。結果は `chrome.storage` にキャッシュし、期限切れのものは 1 日 1 回削除する |
| `src/flags.js` | 国名から ISO コードへの変換と、国旗画像（X の Twemoji）の URL 生成 |
| `popup/` | 設定画面（有効/無効、VPN マークの表示、リクエスト間隔、キャッシュ保持期間、キャッシュ削除） |
| `_locales/` | 各言語の表示テキスト |
| `icons/` | 拡張機能のアイコン |

## 注意

- X の非公式 API を使っているため、X 側の仕様変更で動かなくなることがあります。
- レート制限（HTTP 429）に達したら、制限が解除されるまで自動で待ちます。
- VPN の判定は X によるもので、正確とは限りません。
